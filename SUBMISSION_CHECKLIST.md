# Submission checklist
- [ ] Backend runs (`npm run dev`) against MySQL and seeds
- [ ] Clinician dashboard logs in to the real API
- [ ] Flutter app compiled and run on a device (needs `flutter create .`, see patient_app docs)
- [ ] Capture-quality + abstention verified on a device
- [ ] Baseline comparison run on recorded data (results stay PENDING until expert labels exist)
- [ ] Docs complete (README, ARCHITECTURE, POSE_ANALYSIS, DATA_FLOW, PRIVACY_AND_CONSENT, EVALUATION, VIVA_GUIDE)
- [ ] Physiotherapist verification of criteria (required before any clinical claim)
